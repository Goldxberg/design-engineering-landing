How these cards work

  • 3D perspective follows your cursor with spring physics
  • Radial glow tracks mouse position via CSS custom properties
  • Border shine uses mask-composite for the edge highlight
  • Icons float above the card surface using translateZ
  • Spring easing via cubic-bezier for natural deceleration
  • Zero dependencies — vanilla CSS + ~30 lines of JS
