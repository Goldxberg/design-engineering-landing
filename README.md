# goldbergai.com

My personal site. Live at **[goldbergai.com](https://goldbergai.com)**.

No framework, no build step. Static HTML, CSS and vanilla JS — partly because it's
faster that way, mostly because I wanted to understand every line of it.

Each page is one interaction idea, built on its own:

| Page | What it does |
|------|--------------|
| `magnetic-cards.html` | Cards that lean toward the cursor and settle back |
| `scroll-gears.html` | Gears that turn with scroll position |
| `curved-scrollbar.html` | A scrollbar that follows a curve instead of a straight track |
| `stroke-text.html` | Type that draws itself in outline, then fills |
| `pip-video.html` | Picture-in-picture that docks and undocks on scroll |
| `materials.html` | Surface and light experiments |
| `startup-style.html` | A landing page in the standard startup shape, as a control |

Built with Claude. I describe the interaction, read the result, and push back until it
feels right — which is usually the slow part.
